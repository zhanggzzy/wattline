## Why

AN-220 需要查看超过机器详情近期窗口的历史。现有冷归档在本地保存了这些样本，工作台没有对应的查看入口。

## What Changes

- 在整机详情提供历史归档分析按钮。分析页显示实际解压工作的百分比，并在成功后绘制该机器的归档指标折线图。
- 支持按归档时区选择起止日期，提供无归档、区间无样本、失败重试和重复打开的反馈。
- 通过合成 gzip、实际 API 与浏览器检查验收日期边界、机器隔离和临时数据回收。现有机器、GPU 和总览的近期趋势接口及数据格式继续兼容。

## Capabilities

### New Capabilities

- `machine-archive-analysis` 提供机器详情入口、冷归档解压进度及按日期筛选的整机归档趋势。

### Modified Capabilities

## Impact

机器详情、图表组件、FastAPI 和日归档数据读取会涉及此变更。仍使用已有 v1 gzip 归档、归档时区和 Python 依赖。上线无需配置或存储迁移。
