# Proposal

## Why

侧栏收起后目前只剩状态圆点，用户无法从导航辨认目标机器是 B300、PRO 6000、Spark 还是 5090。AN-60 已验收方案 A「机型轮廓」，AN-62 要求在实际折叠尺寸下恢复机器身份，同时保留既有状态、选中、键盘和悬停行为。

## What Changes

- 收起侧栏的机器按钮显示单色机型轮廓：B300 为厚重机柜，RTX PRO 6000 为双槽卡，GB10 / DGX Spark 为紧凑方盒，RTX 5090 为双风扇卡。无法可靠识别时使用通用主机轮廓。
- 机型只依据采集到的 GPU 产品名映射。设备型号缺失、未知，或同一机器混有多类已知型号时，不使用猜测，显示通用主机轮廓。
- 悬停提示和键盘聚焦提示包含实例名、状态和所有可用的完整 GPU 型号；同型号多实例在收起侧栏显示由实例名派生的简短后缀，保证可见区分。
- 轮廓使用 `currentColor` 单色描边，不占用在线状态颜色；状态圆点、选中态、导航、展开侧栏和窄屏行为保持。
- 展开侧栏的机器行沿用同一轮廓，并继续显示实例名和状态。

## Capabilities

### New Capabilities

<!-- 无。 -->

### Modified Capabilities

- `dashboard-focus-layout`: 紧凑导航由「仅状态」改为「机型轮廓 + 独立状态」，并新增可靠机型映射、回退、完整型号提示和同型号实例区分要求。

## Impact

- 代码：`wattline/static/monitor.js`（机型映射、轮廓标记、后缀与可访问名称）、`wattline/static/monitor.css`（轮廓、折叠布局、状态点定位）。
- 测试与验证：`tools/browser_smoke.py` 的合成 API 浏览器检查；OpenSpec strict 校验。
- 数据与接口：不新增机器配置字段，不修改采集、快照、历史或 HTTP 契约。旧配置和没有设备清单的机器自然回退到通用轮廓。
- 兼容性：无持久化 schema 变更；既有选中、导航、状态和展开行为保持。收起侧栏的视觉内容变化是本变更的预期行为，不构成 API 破坏。
- 不涉及真实节点、采集、部署或用户实例数据。
