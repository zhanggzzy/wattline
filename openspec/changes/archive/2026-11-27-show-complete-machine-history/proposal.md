## Why

AN-238（实施 AN-240，来源 AN-220）的历史归档分析只读取已发布的 gzip，遗漏最近七天和仍留在指标库的较旧样本。没有冷归档时，即使机器已有监控记录，用户也看不到历史趋势。

## What Changes

- 机器历史归档分析合并本地指标库原始层、压实层和已发布冷归档。无需等待首次归档即可查看已有历史。
- 起止日期默认覆盖所选机器或来源实际有样本的首末日。用户可按归档时区跨层筛选，起止日均包含在内。
- 验收检查冷热交界、维护前后覆盖、同来源同时间去重、机器与来源隔离、各类空态以及进度、失败重试和临时回收。

## Impact

改动涉及历史分析服务、双语页面文案、说明及合成 API 和浏览器检查。沿用现有 API 路径、指标、来源、时区、近期趋势和临时工作区生命周期。兼容现有 SQLite 结构和 v1 gzip，无需数据迁移或新增依赖。
